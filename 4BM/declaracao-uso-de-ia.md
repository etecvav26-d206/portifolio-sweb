# DECLARAÇÃO DE USO DE INTELIGÊNCIA ARTIFICIAL

**Atividade:** Sistema de Gestão para Gráfica (SWEB, 4º bimestre)
**Instituição:** Etec Vasco Antônio Venchiarutti, 2º D INFONET
**Integrantes:** Otávio Giovanelli Biazzi, Pedro Henrique Miranda, Laura Cristina Gonçalves da Cruz e Pedro Henrique Dalle Molle Godoi

Esta declaração segue a [Política de Uso de Inteligência Artificial em Atividades Acadêmicas](https://github.com/ronildo-ferreira/ronildo-human-layer/blob/main/01-EtecVAV/politica-de-uso-de-ia.md) do professor Ronildo e informa, para cada uso de IA generativa, a ferramenta, a etapa, a finalidade e a forma de validação.

## Resumo

A ideia criativa, a estrutura do sistema e a maior parte do código foram feitas pelo grupo. A IA foi usada como apoio. Ela gerou imagens de referência para ter ideias de layout, ajudou a desenvolver partes do código e a apontar o que podia ser melhorado, e respondeu dúvidas sobre qual caminho seguir, por que escolher uma abordagem em vez de outra e como cada parte funciona. No fim, ela também fez uma revisão do projeto.

## Usos declarados

| Ferramenta | Etapa | Finalidade | Validação |
| ---------- | ----- | ---------- | --------- |
| ChatGPT Images (OpenAI) | Planejamento do layout | Gerar imagens de referência para ter ideias de telas e da identidade visual | As imagens serviram só como inspiração; o layout final foi decidido e feito pelo grupo, e nenhuma delas foi usada no sistema |
| Nano Banana 2 (Google) | Planejamento do layout | Gerar imagens de referência para comparar ideias visuais | Mesma forma do item anterior: o grupo escolheu o que aproveitar e montou o próprio layout |
| ChatGPT e Claude | Plano de funcionalidades (documento entregue em 26/10) | Organizar as ideias, revisar o texto e estruturar os requisitos | As funcionalidades e as decisões finais foram definidas e revisadas pelo grupo |
| ChatGPT e Claude | Desenvolvimento | Ajudar a desenvolver partes do código PHP, SQL e CSS e identificar o que podia ser melhorado (por exemplo, a organização do CSS) | O código foi lido, ajustado e testado pelo grupo no XAMPP, tela por tela |
| ChatGPT e Claude | Desenvolvimento | Tirar dúvidas: qual o melhor caminho a seguir, por que usar uma abordagem e não outra (ex.: transação na venda, inativar em vez de excluir, `password_hash`) e como cada parte funciona | As explicações foram conferidas na documentação oficial do PHP e do MySQL e testadas no sistema |
| Claude (Anthropic) | Revisão final | Revisar o projeto, adicionar comentários explicativos no código, corrigir detalhes (instalador restrito ao próprio computador, mensagem de lista vazia no painel, nomes das cores no CSS), simplificar alguns textos das telas e ajudar a organizar a entrega no GitHub | As alterações foram revisadas pelo grupo e todas as telas foram testadas novamente depois da revisão |
| Claude (Anthropic) | Relatório do projeto | Ajudar na escrita do relatório (`docs/relatorio-projeto.md`), organizando o texto e a descrição das telas a partir das informações do grupo | O grupo leu, revisou e conferiu o relatório com o sistema funcionando |

## Responsabilidade do grupo

Todo o conteúdo entregue é de responsabilidade do grupo. Cada integrante leu o sistema como um todo e consegue explicar as partes que desenvolveu, as principais decisões do projeto e o funcionamento geral.

As fotos dos produtos não foram geradas por IA. São imagens de licença livre, com os autores listados em [`sistema-grafica/assets/img/CREDITOS.txt`](sistema-grafica/assets/img/CREDITOS.txt).
